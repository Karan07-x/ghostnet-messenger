## 🚀 What is GhostNet?

GhostNet is a **peer-to-peer messaging app** that works **without internet**. It uses WebRTC technology to create direct connections between devices, making it perfect for:

- 🏕️ **Disaster zones** where internet is down
- 🎪 **Concerts/Events** with overloaded networks  
- 🏫 **Campus/College** communication
- ✈️ **Flights** (Airplane mode? No problem!)
- 🌍 **Rural areas** with limited connectivity

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📡 **P2P Messaging** | Direct device-to-device communication |
| 🔒 **End-to-End Encrypted** | Only sender and receiver can read messages |
| 📁 **File Sharing** | Send images, documents, and files instantly |
| 👥 **Group Chat** | Multiple peers can join the same room |
| 🌐 **No Internet Required** | Works on local network or hotspot |
| 📱 **Mobile Responsive** | Works on any device with a browser |
| 🎨 **Modern UI** | Beautiful dark theme with animations |

## 🛠️ Tech Stack

**Frontend:**
- React 18 + Vite
- Tailwind CSS
- Simple-Peer (WebRTC wrapper)
- Socket.io Client

**Backend:**
- Node.js + Express
- Socket.io (Signaling server)
- WebRTC ICE/STUN/TURN
